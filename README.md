# Jest Math Utils ➕➖✖️➗

Небольшая утилита с базовыми математическими функциями, написанная на JavaScript. Проект создан **для практики** написания модульных тестов (Unit-тестов) с использованием популярного фреймворка **Jest**.

## 🧮 Доступные функции

В основном файле `mathUtils.js` реализованы и экспортируются следующие функции:

*   **`sum(a, b)`** — возвращает сумму двух чисел.
*   **`multiply(a, b)`** — возвращает произведение двух чисел.
*   **`divide(a, b)`** — делит число `a` на `b`. Если `b` равно нулю, функция выбрасывает ошибку: `"Деление на ноль невозможно"`.
*   **`isEven(n)`** — возвращает `true`, если число четное, и `false`, если нечетное.

## 🛠 Используемые технологии

*   **Node.js** — среда выполнения JavaScript.
*   **Jest (v30)** — мощный и быстрый фреймворк для тестирования JS-кода.

## 🚀 Начало работы

### 1. Клонирование репозитория
```bash
git clone https://github.com/orifjoan-dev/jest-math-utils.git
cd jest-math-utils
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск тестов
Все тесты находятся в папке tests/ (файл mathUtils.test.js). Чтобы запустить проверку работоспособности всех функций, выполните:
```bash
npm test
```

## 💡 Пример использования кода
Вы можете импортировать функции в любой свой Node.js скрипт:
```bash
const { sum, multiply, divide, isEven } = require('./mathUtils');

console.log(sum(2, 3));        // Выведет: 5
console.log(multiply(4, 5));   // Выведет: 20
console.log(divide(10, 2));    // Выведет: 5
console.log(isEven(4));        // Выведет: true

// Обработка ошибки деления на ноль
try {
  divide(10, 0); 
} catch (error) {
  console.error(error.message); // Выведет: "Деление на ноль невозможно"
}
```

## 📖 Чему можно научиться на этом проекте?
Этот репозиторий отлично демонстрирует базовые принципы написания тестов:
Проверка позитивных сценариев (успешное сложение/умножение).
Проверка негативных сценариев (обработка исключений, например, тестирование того, что функция выбрасывает ошибку при делении на ноль через toThrow).
Проверка возвращаемых булевых значений (toBe(true) / toBe(false)).
